# 🎮 Telegram Event Bot

Telegram-бот для проведения интерактивных групповых событий: **Аукцион**, **Казино** и **Случайный розыгрыш**.

---

## 📁 Структура проекта

```
telegram_event_bot/
├── bot.py              ← Точка входа
├── config.py           ← Токен, ID админов, настройки, шаблоны по умолчанию
├── admin_panel.py      ← Полный интерфейс меню администратора
├── auction.py          ← Логика аукциона
├── casino.py           ← Логика казино (Telegram 🎰 слот-машина)
├── random_event.py     ← Логика случайного розыгрыша (мультипобедители)
├── ignore_system.py    ← Управление списком игнора
├── emoji_manager.py    ← Кастомные и Premium-эмодзи Telegram
├── message_manager.py  ← Редактируемые шаблоны сообщений
├── logger.py           ← Логирование в файл и в ЛС
├── admins.txt          ← ID администраторов (по одному на строку)
├── requirements.txt
└── README.md
```

## 🔨 Аукцион — обновлённые правила

- **Таймер НЕ идёт до первой ставки** — участники могут спокойно прочитать условия
- **Первая ставка** запускает обратный отсчёт (N секунд)
- **Каждая новая ставка от другого участника** полностью сбрасывает таймер
- **Тот же самый лидер** не может сбросить свой собственный таймер — это предотвращает злоупотребления
- Отсчёт на **10с, 5, 4, 3, 2, 1** секундах (только после первой ставки)
- По истечении таймера бот отправляет **сообщение о победителе** в группу
- Шаблон победного сообщения редактируется через `AUCTION_WIN`

Примеры:
```
/startauction           → 30 сек, приз "Сюрприз"
/startauction 60        → 60 сек, приз "Сюрприз"
/startauction 45 500 Stars → 45 сек, приз "500 Stars"
```

## 🎰 Казино — настоящая Telegram слот-машина

- Участники отправляют **эмодзи 🎰** через меню стикеров/эмодзи Telegram
- Бот читает **реальное значение слота**, установленное серверами Telegram (1–64)
- Значение **64 = 7|7|7 = джекпот** → победитель!
- Значения **60–63** — "почти победа" (два семёрки на барабанах)
- Боту **не нужно генерировать случайные числа** — Telegram делает это честно на своей стороне

> **Важно:** участники должны отправлять именно эмодзи 🎰 через стандартное меню Telegram (Dice/Slot Machine), а не текстовый символ 🎰. Только тогда бот получает реальный результат барабанов.

Пример:
```
/startcasino 1000 Stars
```

## 🍀 Случайный розыгрыш — мультипобедители

Теперь можно задать **количество победителей**. Бот продолжает розыгрыш после каждого победителя до достижения нужного числа или до остановки администратором.

Формат команды:
```
/startevent [шанс%] [количество_победителей] [приз...]
```

Примеры:
```
/startevent                    → 5%, 1 победитель, приз "Сюрприз"
/startevent 5                  → 5%, 1 победитель
/startevent 5 Сюрприз          → 5%, 1 победитель, приз "Сюрприз"
/startevent 5 3 Сюрприз        → 5%, 3 победителя
/startevent 10 5 500 Stars     → 10%, 5 победителей, приз "500 Stars"
```

- Один и тот же пользователь **не может выиграть дважды** в одном розыгрыше
- После каждого победителя бот сообщает, сколько мест ещё осталось
- Когда все победители найдены — итоговое сообщение со списком всех победителей
- `/stopevent` останавливает с показом текущих победителей

## 🎨 Кастомные эмодзи — обычные и Premium

Установить обычный Unicode-эмодзи:
```
/setemoji EMOJI_WIN 🏆
```

Установить **Telegram Premium анимированный эмодзи**:
```
/setemoji EMOJI_WIN tg:5413572157940735873:🏆
```
Формат: `tg:<emoji_id>:<запасной_символ>`

> **Как найти emoji_id:** Перешлите анимированный эмодзи боту [@getidsbot](https://t.me/getidsbot)

## ✏️ Шаблоны сообщений

```
/setmessage AUCTION_WIN {EMOJI_WINNER} <b>Победитель: @{winner}!</b>\nПриз: {prize}
/resetmessage AUCTION_WIN
```

### Доступные плейсхолдеры
| Плейсхолдер | Описание |
|-------------|----------|
| `{EMOJI_WIN}`, `{EMOJI_FIRE}` и др. | Текущий эмодзи |
| `{prize}` | Текст приза |
| `{winner}` | Никнейм победителя |
| `{username}` | Никнейм участника |
| `{bid_count}` | Количество ставок (аукцион) |
| `{remaining}` | Оставшееся время в секундах (аукцион) |
| `{duration}` | Длительность аукциона в секундах |
| `{chance}` | Шанс победы в % (розыгрыш) |
| `{max_winners}` | Кол-во победителей (розыгрыш) |
| `{attempts}` | Всего попыток (розыгрыш) |
| `{winners_list}` | Список победителей (итог розыгрыша) |
| `{label}` | Метка отсчёта, например "10 секунд" |
| `{leader}` | Текущий лидер аукциона |

## 📊 Управление активными событиями

В меню администратора → **📊 Активные события**:
- Просмотр всех запущенных событий во всех чатах
- Для каждого события можно:
  - **✏️ Изменить приз** — сменить прямо в ходе события
  - **⏱ Продлить +60с** — добавить 60 секунд к аукциону
  - **🎲 Изменить шанс %** — изменить вероятность победы в розыгрыше
  - **🛑 Остановить** — принудительно завершить событие
